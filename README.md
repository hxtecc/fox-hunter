# 🦊 银狐猎手 (FoxHunter)

**银狐猎手** 是一款专为抵御钓鱼下载型木马而设计的浏览器安全扩展。它采用多维度启发式检测引擎，在本地实时分析网页风险，不依赖云端查杀，充分保护您的隐私。

---

## ✨ 主要功能

- 🔍 **域名仿冒检测** — 基于 140+ 品牌数据库，精准识别仿冒官网的钓鱼域名
- 📄 **ICP 备案核验** — 智能提取页脚备案号，识别虚假或缺失备案
- 🔒 **SSL 证书检测** — 验证 HTTPS 证书有效性，警告过期或自签名证书
- 📦 **下载链接分析** — 扫描页面中的可执行文件、压缩包等高风险下载链接
- 🌐 **DNS 劫持预警** — 检测 DNS 解析异常，防止流量被篡改
- 🎨 **悬浮球 UI** — 小圆球实时显示风险评分，悬停查看详情，可拖拽、右键菜单
- 📊 **本地缓存与日志** — 检测结果缓存 24 小时，所有日志仅存本地

### 开发者模式手动加载
1. 下载最新 Release 压缩包并解压
2. 打开 Chrome/Edge 扩展管理页面 (`chrome://extensions/`)
3. 开启 **“开发者模式”**
4. 点击 **“加载已解压的扩展程序”**，选择解压后的文件夹
5. 扩展图标将出现在浏览器工具栏中

## 🧭 使用指南

- **悬浮球**：页面右下角显示风险评分（0~200+），颜色代表安全/可疑/高危
- **悬停**：显示详细检测结果（ICP、SSL、命中规则等）
- **右键菜单**：1小时内静默、本网站忽略、查看详情、恢复显示
- **弹窗（Popup）**：点击工具栏图标，可查看当前页面完整风险报告和网络检测
- **设置页**：可自定义阈值、白名单、黑名单、外观主题等

---

## 🔒 隐私承诺

- **完全离线运行**：所有检测逻辑在本地执行，不上传任何数据
- **不收集个人信息**：不记录浏览历史、不追踪用户行为
- **数据自主可控**：白名单、黑名单、日志等全部存储在本地，用户可随时清除
